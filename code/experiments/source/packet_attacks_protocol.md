# Complete-packet attack library

The protocol defines clean reports, fixed target shifts, reference spoofing at
the declared gain and target settings, reference reversal, and whole-packet
translations. Only controlled source identities may be changed; all honest
rows remain identical. The fixed main library excludes whole-packet translations,
which are retained and reported separately as controls.

All numerical settings, source identities, and resource hashes are recorded in
packet_attacks_protocol.json. Public inputs determine acquisition before reports
are fulfilled. Predictors receive the same purchased reports within each profile;
evaluation truths are accessed only after predictions have been saved.
